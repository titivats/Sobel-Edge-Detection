# AVTR — Automatic Vision Tab Router

Windows desktop software for Aurotek Router AUO6000 export review, Sobel edge
tuning, GOOD/NG labeling and DINOv2 classification.

See [OPERATIONS.md](OPERATIONS.md) for installation, the three Settings tabs,
model screening, test commands and current limitations.

Run `production_app.py` or `run.bat`. `app.py` is the legacy Engineering Studio.
The conveyor link is simulation-only and physical PLC output is disabled.
Machine exports, runtime configuration, labels and model weights stay local.
