วิธีติดตั้ง AVTR บน Windows 64 บิต

1. คัดลอกไฟล์ AVTR-Setup-x64.exe ไปยังเครื่องที่จะใช้งาน
   ตัวติดตั้งมี Python และโมเดลมาให้แล้ว ติดตั้งแบบออฟไลน์ได้

2. ดับเบิลคลิก AVTR-Setup-x64.exe
   ใช้โฟลเดอร์ที่โปรแกรมเลือกให้ แล้วกด Install (ติดตั้ง)

3. รอจนติดตั้งเสร็จ แล้วกด Finish (เสร็จสิ้น)
   หากแอปยังไม่เปิด ให้กดปุ่ม Start ของ Windows
   พิมพ์ AVTR Router Vision Studio แล้วกด Enter

4. เมื่อเปิดครั้งแรก หากมีหน้าต่างให้ตั้งรหัสผ่าน ให้ตั้งและเก็บรหัสไว้
   รหัสนี้ใช้เข้าเมนู SETTING ของ AVTR

หลังเปิดโปรแกรม
หากเห็น FAULT-HOLD ให้เข้า SETTING → DATA SOURCE
เลือกโฟลเดอร์เครื่องที่มี Sep.Net และ SepData อยู่คู่กัน
อ่านขั้นตอนตั้งค่าบอร์ดต่อในไฟล์ README-TH.txt ที่อยู่ในโฟลเดอร์ติดตั้ง

กรณี Windows แจ้งว่าองค์กรบล็อกแอป
ส่ง AVTR-Setup-x64.exe และไฟล์ SHA256SUMS.txt ที่อยู่ข้างกันให้ฝ่าย IT
เพื่อขออนุมัติทั้งตัวติดตั้ง AVTR-Setup-x64.exe และตัวโปรแกรม AVTR.exe
