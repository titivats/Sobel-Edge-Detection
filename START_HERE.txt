SOBEL + YOLO CLASSIFICATION QUICK START
=======================================

Finetune.bat
  Create and tune Sobel images.

image_classification\Train_model.bat
  Read the newest Label Studio JSON, prepare PASS/NG folders, and train.

image_classification\Predict_model.bat
  Classify images placed in image_classification\predict_images.

Realtime_Dashboard.bat
  Open the realtime PASS/NG classification dashboard.

Label Studio JSON folder:
  image_classification\Export JSON from label-studio

Trained model:
  image_classification\runs\pass_ng_classifier\weights\best.pt
