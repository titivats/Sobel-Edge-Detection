AVTR สำหรับ Windows x64

หลังติดตั้ง เปิด AVTR จาก Start Menu หรือดับเบิลคลิก AVTR.exe ในโฟลเดอร์โปรแกรม
ถ้าคัดลอกแบบพกพา ให้คัดลอกทั้งโฟลเดอร์ AVTR รวมทั้ง _runtime และ models
เลือกตำแหน่งที่บัญชีผู้ใช้มีสิทธิ์เขียน เพื่อเก็บค่าตั้ง โมเดล ประวัติ และหลักฐานการตรวจ

เมื่อเปิดครั้งแรก ให้ตั้งรหัสผ่าน SETTING สำหรับบัญชี Windows นี้
หากบัญชีได้ตั้ง AVTR_SETTINGS_PASSWORD ไว้แล้ว โปรแกรมจะใช้ค่านั้น

เริ่มงานกับ AUO6000
1. เข้า SETTING → DATA SOURCE และเลือกโฟลเดอร์ที่มี Sep.Net และ SepData
2. เลือก Recipe และใส่จำนวน CUT ตามโปรแกรมบนเครื่องจริง
3. เลือก CAPTURE JSON FOLDER ที่รับข้อมูลราย CUT จากรอบเดียวกับภาพและ Result CSV
4. ตรวจ SPEC และยืนยันด้าน A/B ด้วย SAVE EDGE ให้ครบทุก CUT
5. เทรนโมเดลสำหรับโปรแกรมที่เลือกตามความจำเป็น จากนั้น TEST และ SAVE SETTINGS
6. ปิด Settings แล้วกด ACK / RESET และ START AUTO เมื่อข้อมูลพร้อม

โปรแกรมที่ตั้งค่าใหม่จะอยู่ใน HOLD จนกว่าจะมีข้อมูลและโมเดลที่อนุมัติตรงกับโปรแกรมเครื่อง
ชุดนี้รวม Python, Qt, OpenCV, PyTorch สำหรับ CPU และน้ำหนัก DINOv2 ViT-S/14 สำหรับใช้แบบออฟไลน์
ใช้ PLC จำลองในการทดลอง ให้ผู้ตรวจยืนยันร่องที่วัดและเทียบค่ามิลลิเมตรกับชิ้นงานจริง
